# DSH Market · 视觉与交互原型

双击 `index.html` 即可预览。所有样式、脚本和 60 个插件数据已内嵌，不需要安装依赖或启动服务。

## 修改入口

| 文件 | 修改内容 |
| --- | --- |
| `concept.html` | 基础页面结构、文案、基础 CSS。模板，不是最终预览页。 |
| `enhancements.css` | 收藏、快捷搜索、列表模式、详情标签和响应式样式。 |
| `motion.css` | 卡片抬升与光晕、按钮反馈、悬停和动效曲线。 |
| `market-app.js` | 搜索、分类、排序、收藏、演示添加、撤销、精选切换、详情和本地保存。 |
| `motion.js` | 鼠标倾斜、跟随光晕、点击涟漪、收藏弹跳、滚动入场及面板动画。 |
| `catalog.json` | 独立的 60 个插件数据，可直接增删、修改。 |
| `build-preview.py` | 将模板、交互所需结构、CSS、JS 和插件数据合并成自包含预览页。 |
| `check-interactions.cjs` | 不依赖第三方包的交互逻辑检查，需要 Node.js。 |
| `index.html` | 生成的最终预览页。不要把长期修改只写在此文件中，重新构建会覆盖。 |
| `preview-check.js` | 生成的合并脚本，供语法检查使用，不需要手动编辑。 |

基础布局在 `concept.html`；收藏按钮、快捷搜索框、轮播控制等补充结构由 `build-preview.py` 注入，修改这些结构时编辑构建脚本对应的替换片段。

## 修改后生成预览

在本文件夹终端执行（需要 Python 3，无第三方 Python 依赖）：

```powershell
python .\build-preview.py
```

然后重新打开 `index.html`，或在浏览器按 Ctrl+F5 刷新。

可选检查（需要 Node.js，无 npm 依赖）：

```powershell
node --check .\preview-check.js
node .\check-interactions.cjs
```

检查覆盖应用状态和交互逻辑，不代替浏览器视觉、布局和动画实测。

## 体验功能

- 卡片悬停抬升、轻倾斜、光晕跟随；按钮按压与涟漪；收藏爱心反馈。
- 三套精选内容、主题切换、网格/列表、分类和关键词搜索。
- Ctrl/Command+K 快捷搜索，方向键选择，Enter 打开详情；按 `/` 聚焦页面搜索。
- 收藏与演示添加在浏览器 localStorage 中保存；支持移除、撤销和重置。
- 详情抽屉提供版本记录、相关推荐、复制包名与项目仓库入口。
- 触屏按压反馈；遵循 `prefers-reduced-motion` 关闭动态效果。

添加/移除仅为本地原型交互，没有连接 DSH 插件安装接口。迁入真实 DSH 前，需要接入宿主数据、主题与安装 API。

## 版本说明

本文件夹是当前交互动效版的完整独立副本。仅包含这一版的源码、数据、生成文件和说明；旧版 CSS 与历史预览留在上一级目录。后续请在本文件夹修改和构建。


## 大肥鱼套装板块

本版新增 `suite.css`（板块视觉）、`suite.js`（示例数据、勾选、添加队列、暂停、重试与重置）。在 `suiteItems` 中修改示例插件。所有操作仅是本页内存中的演示，不连接宿主安装服务，不与真实平台通信。

在页面「大肥鱼接入插件」板块中，选择组件后点击安装所选，或一键安装整套。勾选「模拟一次平台添加失败」可体验失败后重试。公共依赖始终自动包含；暂停后可以重试未完成项。

## 可展开套装总览

当前提供大肥鱼接入、自动工作流处理、知识整理与检索三套演示组合。默认全部收起，点击摘要展开，再次点击收起；同组只展开一个套装。各套装的选择和队列分别管理，收起不取消正在进行的模拟任务，刷新页面重置套装演示状态。

在 `suite.js` 顶部的 `packs` 数组增删套装、编辑描述与插件列表。`runtime` 是每套的公共依赖项，始终自动包含。摘要卡片与展开样式位于 `suite.css` 的后半部分。`suite-single.backup.js` 和 `index-before-collapsible.html` 是改为多套装之前的备份，不参与构建。

套装检查：`node check-suite.cjs`。

## 紧凑横排版（当前）

套装区域已改为桌面三列紧凑卡片，只显示名称、简短用途和插件数。点击打开原生模态弹窗展示插件清单与队列，不再推移下方全部插件。可点击关闭按钮、按 Esc 或点击遮罩关闭；关闭不会停止队列。小屏使用横向滑动卡片，避免三张纵向堆叠。

`suite-accordion.backup.js` 和 `index-before-compact-bundles.html` 是横排弹窗改动前的备份，不参与构建。前文的展开式总览说明属于上一版本。

## 颜色与信息层级

`visual-hierarchy.css` 管理当前的套装分色、普通插件分类色和勾选状态层级，加载在其他 CSS 之后。套装使用青绿、靛紫、琥珀三种点缀色；内部插件保留中性底板，通过图标、细边框和选中标识区分。普通插件的分类色映射在 `market-app.js` 的 `categoryColors`，不再按列表位置随机分配。`index-before-color-hierarchy.html` 是本次视觉调整前的备份。
